## 产品概述

为服务器后台指令快捷输入工具的指令增加前置关联指令配置能力。

## 核心功能

- **关联指令配置**：在指令编辑面板（CommandDialog）中，为每个指令增加"前置关联指令"配置区域：
- 复选框：启用/禁用关联指令
- 下拉列表：从所有分类下的现有指令中选择一条作为关联指令（显示格式：`分类/指令名`）
- 数字输入框：配置关联指令执行完毕后到自身指令执行的延迟时长，单位毫秒（范围 0–60000，步进 100）
- **关联指令执行**：点击执行某条指令时，若该指令启用了关联指令：

1. 先查找并执行选定的关联指令（完整走连接检查、参数弹窗、命令发送流程）
2. 按照配置的延迟时长等待后，再执行当前指令自身
3. 关联指令仅触发一层，避免循环（通过 `from_linked` 参数控制）

- **数据持久化**：关联指令配置随指令数据一并保存到 `commands.json`，字段包括 `linked_enabled`（bool）、`linked_command`（对象，含 `category` 和 `name`）、`linked_delay`（int，毫秒），需要兼容老版本已有的配置。

## Tech Stack

- **语言/框架**：Python 3.13 + PyQt5
- **项目形态**：单文件桌面应用（`main.py` 约 2717 行）
- **配置持久化**：本地 JSON 文件（`commands.json`）

## Implementation Approach

### 整体策略

基于现有 `CommandDialog` 和 `execute_command` 进行最小侵入式扩展，不改变现有数据结构和 UI 架构的约定。

### 关键设计决策

1. **UI 扩展**：在 `CommandDialog` 的"持续输出模式"复选框下方新增一个配置区块（复选框 + 下拉框 + `QSpinBox`），与现有表单项风格保持一致。
2. **指令标识**：`linked_command` 保存为 `{"category": "...", "name": "..."}`，确保跨分类同名指令可唯一匹配。
3. **执行层防循环**：给 `execute_command` 增加 `from_linked=False` 形参。当因关联触发执行关联指令时传入 `True`，关联指令内部即使也配置了关联，也不会再次触发，保证"只前置执行一层"。
4. **延迟实现**：利用已有的 `QTimer.singleShot(delay_ms, callback)` 做非阻塞延迟，避免卡死 GUI。
5. **逻辑提取**：将原 `execute_command` 中"连接检查 → 持续运行冲突检查 → 调用 `_execute_command_continue`"的主体逻辑提取到 `_execute_command_main()`，供正常执行和延迟回调复用，避免代码重复。

### 性能与可靠性

- 关联指令查找为内存遍历，数据量极小（通常 < 1000 条指令），时间复杂度 O(n)，无性能瓶颈。
- 延迟为非阻塞定时器，不影响主线程响应。
- 若关联指令已被删除或找不到，在命令日志输出提示并继续执行自身指令，保证可用性。
