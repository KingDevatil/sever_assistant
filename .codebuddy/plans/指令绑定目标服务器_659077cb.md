## 产品概述

为服务器后台指令快捷输入工具增加"指令绑定目标服务器"功能，解决同一台物理服务器（相同IP）配置多个用户账号时，不同指令需要在不同用户下执行的切换问题。

## 核心功能

- **指令配置绑定服务器**：在指令编辑面板中增加"目标服务器"下拉选项，按服务器名称绑定
- **自动切换执行服务器**：点击指令时，若配置了目标服务器，自动切换到对应服务器执行；未配置则保持现有逻辑（当前激活页签或弹框选择）
- **自动连接**：若绑定的服务器未连接，自动调用 `ensure_connection` 尝试连接，连接失败则输出错误日志并终止执行
- **关联指令继承**：前置关联指令继承主指令解析后的目标服务器，防止重复切换
- **兼容旧配置**：旧指令无 `target_server` 字段时，默认走原有执行逻辑

## Tech Stack Selection

- **语言/框架**：Python 3 + PyQt5（与现有项目一致）
- **测试框架**：unittest + unittest.mock（沿用已有测试风格）
- **构建工具**：PyInstaller（与现有打包流程一致）

## Implementation Approach

在现有指令执行链路中插入一层"目标服务器解析"，使指令配置决定实际执行服务器，而非仅依赖 UI 上下文。

**关键决策：**

1. **统一在 `execute_command` 入口解析 target_server**：按钮绑定逻辑无需修改，所有指令按钮的点击最终都进入 `execute_command`，在此处统一处理 target_server，代码侵入性最小。
2. **`from_linked=True` 时不切换服务器**：前置关联指令由主指令传入解析后的 `server_name`，确保关联指令和主指令在同一目标服务器执行（如先 `cd` 再执行）。
3. **`execute_default_command` 优先解析 target_server**：默认面板中的指令若配置了目标服务器，直接定向执行，不再弹框或找当前页签。
4. **`CommandDialog` 增加 `server_manager` 参数**：下拉框数据来源于 `server_manager.servers`，实例化时需传入。

**性能与可靠性：**

- `ensure_connection` 内部会检测连接存活状态，已连接时直接返回 `True`，无额外开销。
- 自动连接失败时通过 `command_log` 输出带时间戳的错误信息，用户可感知。
- 兼容旧配置：所有读取使用 `.get('target_server')`，不存在时返回 `None`。

## Architecture Design

```
指令按钮点击 / 双击
    │
    ├─► server页签按钮 ──► execute_command(srv, cmd)
    │                        │
    │                        ▼
    │                   [解析 target_server]
    │                   from_linked=False 且 cmd 配置了 target_server?
    │                   ├─ 是: server_name = target_server
    │                   │      ensure_connection(server_name)
    │                   │      失败则记录日志并返回
    │                   └─ 否: 保持传入的 server_name
    │                        │
    │                   [处理前置关联指令]
    │                   递归调用 execute_command(server_name, linked_cmd, from_linked=True)
    │                        │
    │                        ▼
    │                   _execute_command_main(server_name, cmd)
    │
    └─► 默认面板按钮 ──► execute_default_command(cmd)
                              │
                              ▼
                         [解析 target_server]
                         配置了 target_server?
                         ├─ 是: ensure_connection(target) → execute_command(target, cmd)
                         └─ 否: 原有逻辑（当前页签 / 弹框）
```

## Key Code Structures

```python
# execute_command 入口修改示意
def execute_command(self, server_name, command_info, from_linked=False):
    # 仅主指令可切换目标服务器，关联指令继承主指令解析后的服务器
    if not from_linked:
        target = command_info.get('target_server')
        if target:
            server_name = target
            if not self.server_manager.ensure_connection(server_name):
                self.command_log.append(f"[{time.strftime('%Y-%m-%d %H:%M:%S')}] 错误: 无法连接到目标服务器 {server_name}")
                return
    # ... 原有前置关联指令逻辑不变
```
